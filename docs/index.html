Event Simulator
Python · Faker
Generates realistic user journeys — page views, cart adds, and orders — mimicking 50 concurrent users browsing 8 products. Each journey follows a realistic conversion funnel: all users view a page, 60% add to cart, 40% of those place an order.
page_view add_to_cart order_placed 50 active users JSON events
Apache Kafka
Confluent 7.4 · Docker
Decoupled message broker. Events are written to the ecommerce_events topic. Two listener addresses are configured — one for the Python producer on Windows, one for Spark inside Docker — solving the container networking problem.
topic: ecommerce_events EXTERNAL: localhost:9092 INTERNAL: kafka:29092 Zookeeper
Spark Structured Streaming
Apache Spark 3.5 · Docker
Reads the Kafka topic as a continuous stream. Parses raw JSON bytes against a defined schema, casts timestamps, adds ingestion metadata, and writes every event to the Bronze Delta Lake table in append mode. Checkpointing ensures no events are lost if the job restarts.
readStream from_json append mode checkpointing Spark UI: 4040
Medallion Architecture
Bronze
Raw Layer
Every event stored exactly as received. No changes, no filtering. Permanent audit trail — if anything breaks downstream, replay starts here.
Delta Lakeappend only_delta_log/
Silver
Clean Layer
Nulls removed, duplicates dropped, events split into three typed tables. Delta MERGE makes the job safe to re-run without creating duplicates.
page_viewscart_eventsordersMERGE upsert
Gold
Business Layer
dbt transforms Silver into business metrics — revenue, conversion rates, product performance. Materialized as tables for fast dashboard queries.
fct_ordersfct_funneldim_products
dbt + DuckDB
dbt-core · dbt-duckdb
Six SQL models build the Gold layer. Staging views wrap the Silver tables with clean column names and types. Mart tables compute KPIs: total revenue, daily conversion rates, average order value, and product performance. Eight automated tests run on every build.
3 staging views 3 mart tables 8 data tests lineage graph docs: port 8081
Apache Airflow
Airflow 2.8 · LocalExecutor · PostgreSQL
Orchestrates the full batch pipeline on an hourly cron schedule. The DAG checks Bronze is healthy before running Silver, then runs dbt models, then dbt tests. Failed tasks retry twice with a 5-minute delay. Everything is defined as code in a single DAG file.
schedule: 0 * * * * retries: 2 PythonOperator BashOperator UI: port 8082
Apache Superset
Superset 3.0 · duckdb-engine
Business intelligence layer connected directly to the Gold DuckDB database. Four charts on one dashboard: a revenue KPI with trendline, revenue by product category, the user conversion funnel, and a product performance ranking table.
Total Revenue KPI Revenue by Category Conversion Funnel Product Performance UI: port 8083
